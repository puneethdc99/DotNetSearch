# Security Policy

## Supported Versions

Only the latest version of DotNetSearch is actively maintained with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within DotNetSearch, please do not open a public GitHub issue. Instead, report it privately:

1. Use GitHub's private vulnerability reporting feature on this repository under the **Security** tab.
2. Alternatively, contact the maintainer directly: **Puneeth DC** via GitHub [@puneethdc99](https://github.com/puneethdc99).

Please include:
- A description of the vulnerability and its potential impact.
- Steps or a proof-of-concept to reproduce the behavior.
- Any suggested fixes or mitigations.

You will receive an acknowledgment within 48 hours, followed by updates on the timeline for a fix.
